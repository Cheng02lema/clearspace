# 使用边界与恢复

澄界是一款面向 Claude 本地数据的独立清理工具，不代表 Anthropic。清理本机文件或调整浏览器与系统设置，不能保证改变服务器端记录、账号状态或所有浏览器和设备指纹。

## 清理范围

- Windows 全局发现会检查可访问的卷；macOS 仅检查当前用户主目录和通过 `CLAUDE_CONFIG_DIR` 显式指定的目录。发现过程按目录结构和规则识别候选项；系统目录、程序目录、应用自身目录及部分链接会被排除。扫描受时间、深度、条目数量、权限和文件变化限制，结果可能不完整。
- 浏览器“缓存与全部 Cookie”覆盖受支持浏览器配置中的**所有网站**，包括站点存储和登录状态。mail.com Cookie 是独立项目。
- Claude Code 目录、全局状态和环境变量可能包含配置、会话、凭据或 MCP 设置。不要假设清理是可逆的。
- 自定义 `CLAUDE_CONFIG_DIR` 可能混有其他文件；允许选择识别出的单个配置或凭据文件，但禁止完整清理该自定义目录。
- Windows 扫描可能会涉及多个盘符；UNC 路径受到限制，但不要把它理解为对所有映射网络盘都经过了识别与排除。macOS 的显式配置目录可能位于其他卷，跨卷隔离无法安全执行时会跳过。
- macOS 不清理 Safari 和钥匙串凭据。清理 Claude 环境变量可能删除用户 shell 配置中匹配的整行，不创建备份。

## 操作影响

确认对话框显示即将处理的项目和路径；清理前还会再次检查。清理不可恢复，且不会创建持久备份。关闭浏览器可能中断下载、未保存的表单和私密窗口。DNS、浏览器策略、系统定位、时区和区域变更可能影响网络与应用；某些操作需要 Windows 管理员授权。

一键启动选择可执行的非恢复操作。互斥项会择一，重叠或被阻止的清理项会列出并跳过；如果清理路径在确认后改变，流程会停止。单项失败与部分完成会显示在结果中，不等于所有操作均成功。

## 一键恢复

清理的数据没有备份，**无法由本软件恢复**。当前一键恢复仅尝试恢复：

1. 本次操作新创建并保留有效状态记录的 DNS 配置。
2. 本次操作新创建并保留有效状态记录的浏览器定位与语言配置。

以上两类自动恢复目前仅在 Windows 提供；macOS 一键恢复不能自动恢复清理的数据或本次修改的设置。它不会自动恢复其他没有原值记录的设置，也不保证成功。若修改前已有旧的恢复记录、记录不可读取或内容发生变化，本功能会跳过对应项。上次的一键操作仍有可恢复的设置时，下一次一键启动会被阻止，以免覆盖恢复依据。

“恢复中国北京时间与区域”是设为指定地区的独立操作，并非恢复任意原始地区。网络恢复页面提供独立的网络诊断，不应被理解为完整系统还原。

## 联网

扫描和文件清理由本地程序执行，但选择公网地区同步、DNS 保护或 AdGuard 等功能时会访问第三方服务：`ipwho.is`、`ipapi.co`、Cloudflare 连通性检查、DNSCrypt 配置中的解析服务，以及官方扩展商店与 AdGuard 配置页面。网络服务会按其自身规则看到请求来源；浏览器代理、系统代理与 VPN 的路径可能不同。
